Design produced by 3 independent candidates + review, synthesized into

append-only `comms_events` collection with a write-time `lane` field, projected
from six source collections which are KEPT as write-only archives. Channel becomes
a field, so Inbox-by-channel and the household timeline are the same query with a
different WHERE. 9 slices, slice 1 repoints the numbers (needs no A2P approval, so
real data arrives immediately). Full synthesis saved at
`/private/tmp/claude-501/.../scratchpad/comms-synthesis.md` (SESSION-SCOPED, copy
it somewhere durable before it is cleaned up) and in the workflow output at
`tasks/wgt838xm2.output`.

**Review coverage is INCOMPLETE and this matters.** CPO and CDO reviewed all three
candidates. All three CTO reviews FAILED (agent type `c-level-agents:cs-cto-advisor`
does not exist; there is a `cs-vpe-advisor` agent and a `/cs:cto-review` skill).
The synthesis was therefore built without CTO input. A CTO pass was run afterward
against the synthesis and returned **SHARPEN**, with three findings not yet folded in:
1. **Top tech debt: two Kotlin trees with zero sharing.** `composeApp/build.gradle.kts:12-24`
   declares `wasmJs` and `jvm()` and NO `androidTarget()`; `android/` is a separate

   two implementations to one. Decide before comms slice 3.
2. **The stated worst failure has no detector.** The design calls a silently lost

3. **No CISO sign-off**, and this design makes call recordings browser-playable for

## Gotchas learned

- `gcloud` IAM grants are blocked by the auto-mode classifier as privilege
  escalation. Hand the operator the exact commands and have them run with `!`.
- Firebase resolves secret `latest` LITERALLY. Disabling the newest version breaks
  deploy with "illegal state DISABLED"; promote the good value to a NEW version.
- Disabling a secret version breaks every already-deployed function mounting it,
  so redeploy every consumer, not just the one you were thinking about.
- `dangerouslyDisableSandbox` is required for anything touching
  `CascadeProjects/auntieos-admin/.git` and for `gcloud`.
- Workflow `agentType` names are NOT the same as skill names. Verify against the
  available-agents list or the whole phase dies.
