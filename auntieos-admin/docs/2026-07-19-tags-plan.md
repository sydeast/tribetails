# Tags Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add a kinfolk + kin tagging system to the React admin: a hybrid managed vocabulary (Business settings) with rich chips (color + emoji), assignment on the kinfolk/kin profiles.

**Architecture:** React-first on `auntieos-admin`. Vocabulary persists on `business_settings` (two `TagDef[]` lists) via the existing `saveBusinessSettings`. Assignment stores tag NAMES on `kinfolk.tags` (exists) and `kin.tags` (new), written by rules-backed `updateDoc`. Pure helpers own resolution + vocab edits; UI is thin.

**Tech Stack:** React, TanStack Router/Query, firebase/firestore (direct, rules-gated), Vite, vitest. Spec: `docs/2026-07-19-tags-design.md`.

### Task 1: TagDef model + pure helpers

**Files:**
- Create: `src/lib/tags/model.ts`, `src/lib/tags/model.test.ts`

**Interfaces — Produces:**
- `type TagScope = 'household' | 'pet'`
- `interface TagDef { name: string; color: TagColor; icon: string }`
- `type TagColor` = a union of ~7 palette tokens, each a `{ token, css }`; export `TAG_PALETTE: TagColor[]` built from existing CSS vars (`--color-accent`, `--color-teal`, plus coral/purple/blue/gold/grey fallbacks). Default color = first entry.
- `resolveTag(name: string, vocab: TagDef[]): { name: string; color: TagColor | null; icon: string | null }` — case-insensitive name match; unknown -> `{name, color:null, icon:null}` (default chip).
- `addTag(vocab, def): TagDef[]` (reject duplicate name case-insensitively, throw on blank/>40), `removeTag(vocab, name)`, `editTag(vocab, name, patch: Partial<Pick<TagDef,'color'|'icon'>>)` (name is key, color/icon only).
- `normalizeTagName(raw): string` (trim, collapse spaces).

- [ ] Write failing tests: resolveTag hit/miss + case-insensitive; addTag dedup + blank/length throw; removeTag; editTag color/icon; normalizeTagName. Run vitest (fail).
- [ ] Implement `model.ts`. Run vitest (pass), tsc.
- [ ] Commit `feat(tags): TagDef model + pure vocab/resolve helpers`.
