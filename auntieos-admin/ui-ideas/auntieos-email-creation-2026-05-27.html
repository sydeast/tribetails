SuggestionBeyond the current model

The coded EmailTemplate has no per-template enable flag. Today the "active" state lives on the binding (TemplateBinding.active), which the toggle above maps to. Two ideas that would need new fields or callables:

  • A true per-template enabled boolean on the template doc, so a draft can exist without an assignment.
  • An inline merge-field validator that flags tokens not in the known catalog before save.
